Phase 3 · The Pipeline
How transfer learning actually works
Step through each operation and watch the network change.
Click any step to jump directly
Step 1
Pre-train
Train on Task A (large dataset) to build a general-purpose backbone.
Step 2
Remove head
Detach the Task A output layer — it only knows Task A labels.
Step 3
Add new head
Attach a randomly initialized layer for Task B's outputs.
Step 4
Fine-tune
Train on Task B data — new head learns fast, backbone adapts slowly.
Both Task A and Task B feed through the same backbone — only the output head is swapped.
Freezing is useful when Task B is very small — it prevents the backbone from forgetting what it learned on Task A. Only the new head's weights update.
Phase 4 · When To Use It
Transfer learning isn't always the right call
Three conditions determine how much you'll benefit.
① Task A has much more data than Task B
Task A data size 120k
Task B data size 8k
② Both tasks use the same type of input
Both tasks use natural images — conv features transfer almost perfectly.
③ Low-level features are shared between tasks
Early conv layers learn edges and textures — these transfer well. But if Task B is completely unrelated, even early features may not help.
Remember that hospital with 8,000 X-ray images?
In a typical scenario, a team might take a ResNet pretrained on 1.2M natural images, replace the final layer, and fine-tune on their 8,000 scans. Illustrative example — not a fixed benchmark result. Actual gains vary by dataset, model, and domain.

In PyTorch, this looks like:
# Step 1 — load a backbone pretrained on 1.2M images model = torchvision.models.resnet50(pretrained=True) ← pretrained backbone # Step 2 + 3 — remove old head, attach new one for Task B (2 classes) model.fc = nn.Linear(2048, 2) ← replace the head # Optional: freeze backbone so only the new head trains for param in model.parameters(): param.requires_grad = False model.fc.requires_grad_(True) ← only train the new head # Step 4 — train on Task B (your 8,000 X-rays) as usual optimizer = torch.optim.Adam(model.fc.parameters(), lr=1e-3) # ... standard training loop here
