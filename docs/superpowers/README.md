# Superpowers History

This folder is a tracked historical record of earlier implementation plans and design specs.

It is not used by the Next.js app, the Vercel build, production routes, or current maintenance scripts.

Important: old lines such as `REQUIRED SUB-SKILL` describe the workflow used when those notes were created. They are not active instructions for current project maintenance.

## Contents

| Folder | Contents | Current status |
| --- | --- | --- |
| `plans/` | Step-by-step implementation plans for topic preview rollout work. | Historical project memory. |
| `specs/` | Design specs for topic previews and the blog editorial shell. | Historical project memory. |

## Cleanup Decision

Keep this folder for now because it explains why several topic preview files and verification scripts exist.

If the GitHub repository needs a cleaner docs surface later, move the whole folder to a tracked archive path such as `docs/archive/superpowers/` and keep this README-style index with it. Do not delete it until the topic preview design history is no longer useful.
