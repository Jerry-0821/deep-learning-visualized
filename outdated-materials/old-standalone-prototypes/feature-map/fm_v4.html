Phase 1 · The Problem
Raw pixels are the worst possible input
Two images can have nearly identical pixel values but completely different content. And two images of the same thing can look totally different in pixels. Pixels alone are not enough.

These two images represent the same digit. But their pixel-by-pixel difference is enormous. A raw-pixel classifier would see them as very different.
So what do we do?
Instead of feeding raw pixels to the classifier, we first transform the image into feature maps — representations that capture what actually matters: edges, shapes, textures. Two images of the same digit should produce similar edge maps, even if their raw pixels differ.
Phase 2 · The Mechanism
A filter is a small window that slides across the image
Every feature map starts with one filter: a small grid of numbers. It slides across the image, does a dot product at each position, and writes the result. That's it.

Phase 3 · Multiple Filters
Each filter in a layer creates its own map
A single convolutional layer doesn't use just one filter. It uses many — each looking for a different pattern. The same input produces a different output for each filter.

These four maps are the four channels of Layer 1's output. They're not four different images — they're four different re-descriptions of the same image, each emphasizing a different type of pattern.
Phase 4 · Going Deeper
Deeper layers see bigger, more abstract patterns
Layer 2 doesn't look at the original image. It looks at Layer 1's feature maps. Layer 3 looks at Layer 2's output. Each step combines smaller patterns into larger ones.
Step 1: Compare the shallowest and deepest layer
Layer 1 — Vertical edges
The map is sharp and local. Each bright pixel means "there's a vertical edge at exactly this location".
Layer 3 — Core region
The map is blurry and broad. It highlights the general region where the object lives, not any specific edge.
Notice: Layer 1 is precise but local. Layer 3 is broad but abstract. This is not a bug — it's the point. Deeper layers trade spatial precision for semantic meaning.
Step 2: Why does this happen? — The receptive field grows with depth
Click a layer to see its receptive field
Layer 1 filter:
  Sees a 3×3 region of the original image
  → responds to tiny local patterns
Layer 2 filter:
  Sees 3×3 of Layer 1's maps
  → effectively sees a 5×5 region of the original
Layer 3 filter:
  Sees 3×3 of Layer 2's maps
  → effectively sees a 7×7+ region of the original
This is called the receptive field. Deeper layers have larger receptive fields — they're sensitive to bigger regions of the original image, which lets them respond to larger patterns.

Three things to remember
1
A filter is a pattern detector
It slides across the input, computes a dot product at each position, and writes the response. One filter → one feature map.
2
Each layer produces multiple maps
Different filters detect different patterns. The output of a layer is a stack of maps — one per filter — each emphasizing something different.
3
Deeper = larger receptive field = more abstract
Early layers see small local patterns. Deep layers combine earlier responses into bigger, more abstract representations.
