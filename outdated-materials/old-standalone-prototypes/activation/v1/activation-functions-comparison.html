Phase 2.5 · Function Overview
All four activations, side by side
Each column shows one activation's output shape f(z) and its gradient curve g'(z). Background shading marks dead / sensitive / saturated zones.
ReLU
f(z) = max(0, z)
⬛ f(z) — activation
⬛ g'(z) — gradient
Leaky ReLU
f(z) = z if z≥0; 0.01z if z<0
⬛ f(z) — activation
⬛ g'(z) — gradient
Sigmoid
f(z) = 1 / (1 + e-z)
⬛ f(z) — activation
⬛ g'(z) — gradient
Tanh
f(z) = tanh(z)
⬛ f(z) — activation
⬛ g'(z) — gradient
