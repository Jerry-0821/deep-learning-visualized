# Outdated Materials

This folder stores old local prototypes, design references, and generated cache/log files that are not part of the active Next.js website build.

Active website code should stay in:

- `app/`
- `components/`
- `data/`
- `public/`
- `scripts/`
- `topic-design-previews/`

Do not move `topic-design-previews/` here unless the build pipeline is changed first. The build script syncs that folder into `public/topic-design-previews/`.
